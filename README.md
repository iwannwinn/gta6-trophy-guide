Leonida Platinum is an offline web app that guides and tracks all 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy shows its official name, description and grade, a guide written for this page that names its sources beside it, and a roadmap stage. The tracker saves progress in the browser (localStorage), counts progress toward the counted trophies, and exports and imports that progress as a file. Filters cover story, missable, collectibles, activities and online; a spoiler setting hides the names and descriptions of story trophies until they are earned. A six-stage roadmap leads to the platinum, a missables page flags the 15 trophies to do early, and a Next Up planner says what to chase next. Light and dark looks. The game launched yesterday, so where a place or step is not yet pinned down the guide says so plainly instead of inventing one — no guide text is copied from another guide, wiki, video or forum post.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The app loads only its own files and works with the network off.
